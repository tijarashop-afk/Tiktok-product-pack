# TikTok Product Pack

Application mobile-first statique pour transformer l'analyse GPT d'une photo produit en pack TikTok :

- 3 prompts vidéo de 8 secondes à assembler
- voix off prévue dans chaque génération vidéo
- objectif prioritaire : rétention, commentaires, abonnements
- aucun prix demandé, affiché ou inventé
- CTA final : « Disponible sur mon stand et sur Vinted — abonne-toi pour découvrir mes prochains produits ! »
- légende + 5 hashtags

## Utilisation

1. Ouvrir l'application et ajouter une photo produit.
2. Copier le prompt d'analyse GPT.
3. Envoyer ce prompt et la photo dans ChatGPT.
4. Coller l'analyse obtenue dans l'application.
5. Appuyer sur « Générer le pack TikTok ».
6. Copier les 3 prompts dans l'outil vidéo Google, puis assembler les trois clips.

## Déploiement GitHub Pages

Le projet est 100 % statique : `index.html`, `styles.css`, `app.js`.
Aucune clé API n'est stockée dans le code.
